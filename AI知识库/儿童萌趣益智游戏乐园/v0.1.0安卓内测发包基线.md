## 每次发包前检查

- [ ] 代码和知识库工作区无非预期改动：`git status --short`
- [ ] 当前版本号已确认：`儿童萌趣益智游戏乐园/package.json`
- [ ] 执行 `npm.cmd run verify:android` 并通过。
- [ ] 如涉及 TypeScript 或业务代码，执行 `npm.cmd run lint` 并通过。
- [ ] HBuilder X 入口选择构建后的 `dist`，不要选择项目根目录。
- [ ] 图标选择 `public/branding/app-icon-1024.png`。
- [ ] 启动页选择 `public/branding/splash-1080x1920.png`。
- [ ] 权限没有新增定位、通讯录、录音、相机等敏感权限。
- [ ] 真机安装后首页不白屏。
- [ ] 真机图标和启动页正确。
- [ ] 真机 BGM 开关、音效开关可用。
- [ ] 首页三个快捷入口可用：背包补给、今日路线、成长印章。
- [ ] 四个游戏入口可打开。
- [ ] 至少抽测一个游戏完成结算。

## 真机冒烟流程

1. 安装 APK 后冷启动，确认启动页和图标正确。
2. 等待首页加载，确认没有 `app-boot-diagnostics` 面板。
3. 点击 BGM 和音效开关，确认不会卡死或报错。
4. 点击背包补给、今日路线、成长印章，确认能跳到对应区域或页面。
5. 进入数字炸弹、数字华容道、舒尔特训练、五子棋任意一个游戏，确认页面可交互。
6. 完成一次可结算操作，确认积分或结果弹窗正常。
7. 关闭并重新打开 APP，确认本地进度仍可读取。

## 出问题时优先看

- 白屏：先看是否出现 `app-boot-diagnostics`，再按 `HBuilderX打包白屏排查.md`。
- 图标或启动页错误：检查 HBuilder X 是否仍使用默认资源。
- 音频无声：先确认用户手势后播放限制，再确认 BGM 开关状态。
- 数据丢失：检查本地存储是否被清理，当前版本仍使用浏览器本地存储。
