# 儿童萌趣益智游戏乐园 - 安卓打包清单

标签：#HBuilderX #APK #发布检查 #安卓内测

更新时间：2026-06-10

## 当前内测版本

- APP 可见名称：小布智趣岛
- 内部测试版本：v0.1.0
- 源码版本字段：`儿童萌趣益智游戏乐园/package.json` 的 `version`
- 当前打包方式：Vite 构建 `dist`，再由 HBuilder X 打安卓 APK

## 打包前必须执行

在项目目录 `D:\儿童微信小程序开发\儿童萌趣益智游戏乐园` 运行：

```powershell
npm.cmd run verify:android
```

该命令会依次执行：

- `build`：生成最新 `dist`
- `test:android-package`：检查相对资源路径、BGM 文件和 APK 资源风险
- `test:browser:dist`：用浏览器真实加载生产 `dist`，检查挂载、诊断面板、404 和运行时错误

## HBuilder X 打包入口

- 必须选择构建后的 `dist` 目录。
- 不要选择项目根目录。
- 如果修改过代码但没有重新执行 `verify:android`，不要打包。

## 版本与命名

- App 名称：小布智趣岛
- 当前内测版本名：0.1.0
- 每次发给手机测试前，记录测试包版本和 Git 提交号。
- 如果 HBuilder X 有独立 versionCode / versionName，保持 versionName 与 `package.json` 的 `version` 一致。

## 图标与启动页

打包前检查：

- 图标是否是“小布智趣岛”对应图标，而不是 HBuilder 默认图标。
- 启动页是否没有使用 HBuilder 默认模板。
- 启动页颜色与当前绘本探索风格一致。

## 权限

当前 Web 原型不需要主动申请敏感权限。打包前检查：

- 不要开启定位权限。
- 不要开启通讯录权限。
- 不要开启录音权限。
- 不要开启相机权限，除非后续自定义头像明确需要。
- 网络权限如 HBuilder 默认需要可保留，但当前核心体验应支持离线加载本地资源。

## 白屏排查

如果真机仍然白屏：

1. 先看页面是否出现 `app-boot-diagnostics` 启动诊断面板。
2. 如果面板提示资源加载失败，优先检查 HBuilder X 入口是否选错目录。
3. 如果面板提示运行时错误，截图后按错误信息修复。
4. 如果没有面板也白屏，检查安卓 WebView 是否过旧或 HBuilder X 控制台是否有加载错误。

详细排查见：`HBuilderX打包白屏排查.md`。
