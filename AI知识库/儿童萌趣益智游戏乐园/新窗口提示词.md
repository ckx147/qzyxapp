## 已知高价值事实

- `App.tsx` 里的 `handlePointsChange` 是积分统一入口，但多个子组件绕过它直接改 `profile.points`。
- `gameHelpers.ts` 使用 `localStorage` 保存用户、成就、打卡和排行榜。
- `audio.ts` 使用 Web Audio API，不适合直接迁移到微信小程序。
- `metadata.json` 和 `.env.example` 有 Gemini/AI Studio 模板痕迹，但当前源码未看到实际 Gemini 调用。
- 当前目录曾运行 `npm run lint`，失败原因是 `tsc` 不可用，说明依赖未安装或环境未准备好。

## 低 token 工作规则

- 先读知识库短文档，再读任务相关源码。
- 不要默认全项目 `Get-Content`。
- 搜索用 `rg`，先定位再读取局部行。
- 修改前说明将改哪些文件。
- 修改后把重要结论同步回知识库，尤其是已修复问题、验证结果和新风险。
