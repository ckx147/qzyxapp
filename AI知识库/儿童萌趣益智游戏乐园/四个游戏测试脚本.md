# 儿童萌趣益智游戏乐园 - 四个游戏测试脚本

标签：#测试脚本 #游戏验证 #积分回归

## 用途

用于手动验证四个小游戏的主流程、积分结算、成就触发和排行榜同步。执行前建议先运行自动验证。

```powershell
cd "D:\儿童微信小程序开发\儿童萌趣益智游戏乐园"
npm run test:points
npm run test:browser:points
npm run lint
npm run build
```

## 通用前置

- [ ] 启动本地 Web 原型：`npm run dev`。
- [ ] 打开 `http://localhost:3000`。
- [ ] 记录初始积分。
- [ ] 清楚当前是否已经完成当天打卡，避免误把打卡积分算进游戏结算。
- [ ] 每完成一个游戏后记录积分变化、成就弹窗和排行榜展示。

## 数字炸弹

### 胜利路径

1. 进入数字炸弹。
2. 按规则逐步猜测，直到成功避开炸弹并完成胜利条件。
3. 记录结算前积分。
4. 触发胜利结算。
5. 记录结算后积分。

预期：

- [ ] 只发放一次胜利积分。
- [ ] 不出现重复弹窗或重复音效。
- [ ] 成就进度只增加一次。
- [ ] 排行榜显示的当前用户积分与个人积分一致。

### 惩罚鼓励路径

1. 进入数字炸弹。
2. 故意猜中炸弹或触发失败。
3. 记录结算前后积分。

预期：

- [ ] 惩罚或鼓励积分只结算一次。
- [ ] 失败反馈文案适合儿童。
- [ ] 不影响其他游戏记录。

## 数字华容道

1. 进入数字华容道。
2. 选择 3x3 模式完成一局。
3. 记录步数、用时和积分变化。
4. 如可行，再完成 4x4 模式。

预期：

- [ ] 通关积分只加一次。
- [ ] 最佳步数和最佳时间按模式分别更新。
- [ ] 成就进度只增加一次。
- [ ] 返回大厅后积分保持一致。

## 舒尔特训练

1. 进入舒尔特训练。
2. 选择 3x3 模式，按数字顺序完成。
3. 记录用时和积分变化。
4. 如可行，验证 4x4 或 5x5 模式。

预期：

- [ ] 通关积分只加一次。
- [ ] 最佳时间按网格大小分别更新。
- [ ] 快速连点不会导致重复结算。
- [ ] 成就进度只增加一次。

## 五子棋

### 胜利

1. 进入五子棋。
2. 完成一局并让玩家获胜。
3. 记录积分变化和战绩。

预期：

- [ ] 胜利积分只结算一次。
- [ ] 胜场只增加一次。
- [ ] 成就进度只增加一次。

### 失败

1. 进入五子棋。
2. 完成一局并让 AI 获胜。
3. 记录积分变化和战绩。

预期：

- [ ] 失败积分或鼓励分只结算一次。
- [ ] 负场只增加一次。
- [ ] 不误触发胜利成就。

### 平局

1. 尽量填满棋盘形成平局。
2. 记录积分变化和战绩。

预期：

- [ ] 平局只结算一次。
- [ ] 平局记录只增加一次。
- [ ] 不误触发胜利或失败专属成就。

## 成就领奖

1. 打开成就墙。
2. 找到已达成且未领奖的成就。
3. 记录领奖前积分。
4. 点击领奖。
5. 记录领奖后积分。
6. 再次点击或刷新后尝试重复领取。

预期：

- [ ] 成就奖励只发放一次。
- [ ] 已领取状态持久保存。
- [ ] 刷新页面后不能重复领取。
