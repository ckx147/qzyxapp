# 儿童萌趣益智游戏乐园 - 云函数接口契约

标签：#微信云开发 #云函数 #接口契约 #mock

更新时间：2026-06-10

## 当前状态

源码已新增 `src/utils/cloudGameDataPort.ts`，但当前 APP 仍使用本地 `localStorage` port。

本文只定义后续微信云开发的接口契约和 mock 响应，不代表真实云环境已创建。

## 通用约定

- 所有云函数都在服务端通过微信上下文获取 `_openid`，客户端不要传 `_openid`。
- 客户端不要传最终排名，也不要传可信积分余额。
- 时间字段用 ISO 字符串存储；每日签到日期按 Asia/Shanghai 生成 `YYYY-MM-DD`。
- 失败响应统一返回 `code`、`message`、`requestId`。
- 对会改变积分或库存的接口，后续必须加入 `clientRequestId` 幂等字段。

## 通用错误码

| code | 说明 |
| --- | --- |
| `UNAUTHENTICATED` | 无法获取微信登录身份 |
| `FORBIDDEN` | 访问了不属于当前用户的数据 |
| `NOT_FOUND` | 目标记录不存在 |
| `ALREADY_CLAIMED` | 奖励或签到已领取 |
| `INSUFFICIENT_POINTS` | 积分不足 |
| `IDEMPOTENT_REPLAY` | `clientRequestId` 重复提交 |
| `VALIDATION_ERROR` | 请求字段不合法 |
| `INTERNAL_ERROR` | 服务端未知错误 |

## `saveGameState`

当前草案用途：
- 给 Web 原型迁移期保留整体保存口。
- 正式云开发时应逐步拆成 `claimDailyCheckin`、`submitGameResult`、`purchaseFood`、`feedCompanion`、`claimAchievementReward`。

请求：

```json
{
  "state": {
    "profile": {},
    "achievements": [],
    "checkIn": {},
    "leaderboard": []
  }
}
```

响应：

```json
{
  "profile": {},
  "achievements": [],
  "checkIn": {},
  "leaderboard": []
}
```

注意：
- 该接口不应长期承担积分结算。
- 服务端必须重新校验 `_openid` 对应用户。
- 正式上线前，积分变更必须落入 `point_transactions`。

## `getLeaderboard`

职责：
- 从 `user_stats.pointsBalance` 读取前 N 名。
- 只返回公开展示字段。
- 不返回 `_openid`、内部 `userId` 或真实身份字段。

请求：

```json
{
  "limit": 50,
  "scope": "global"
}
```

当前前端草案仍会传 `profile` 和 `localFallback`，只作为迁移期兜底；真实云函数应忽略客户端传入的最终分数和排名。

响应：

```json
{
  "leaderboard": [
    {
      "id": "public_rank_001",
      "nickname": "小布探险家",
      "avatarId": "avatar_dino",
      "points": 920
    },
    {
      "id": "user_xiaobu_001",
      "nickname": "聪明小探险家",
      "avatarId": "avatar_dino",
      "points": 370,
      "isCurrentUser": true
    }
  ]
}
```

## 后续必须补的写操作契约

这些接口比 `saveGameState` 更适合作为正式云端写入口：

- `claimDailyCheckin`
- `submitGameResult`
- `purchaseFood`
- `feedCompanion`
- `claimAchievementReward`

每个写接口都必须包含：
- `clientRequestId`
- 服务端积分计算规则
- 幂等处理
- `point_transactions` 写入策略
- 返回最新 `GameState` 或局部状态补丁

## 前端接入顺序

1. 保持 `gameDataService.ts` 默认本地 port。
2. 在微信小程序环境内实现 `CloudFunctionCaller`，映射到 `wx.cloud.callFunction`。
3. 先只接 `loginOrCreateUser` + `getHomeState` + `getLeaderboard`。
4. 真机验证读取链路后，再拆写操作。
5. 写操作稳定前，不要移除本地 port。
