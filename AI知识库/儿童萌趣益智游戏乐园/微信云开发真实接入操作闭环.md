## 云函数部署顺序

必须按这个顺序：

1. `loginOrCreateUser`
2. `getHomeState`
3. `saveGameState`
4. `getLeaderboard`

每个云函数目录都应作为独立部署包上传，入口为 `index.cjs`，依赖声明在各自的 `package.json` 中。

## 真机验证流程

开启云端开关后，按顺序验证：

1. 清理本地缓存或使用新微信账号进入。
2. 打开首页，确认不会白屏。
3. 确认昵称、积分、背包、签到、成就、排行榜都能正常显示。
4. 完成一次签到，确认积分变化能保存。
5. 完成一次小游戏结算，确认积分和记录能保存。
6. 进入排行榜，确认榜单来自云端排序。
7. 关闭再打开 APP，确认数据从云端恢复。
8. 检查云数据库，没有 `_openid` 泄露到前端展示字段。

## 回退方案

如果真机出现白屏、数据错乱或云函数异常：

1. 立即把实际环境变量改回 `VITE_USE_WECHAT_CLOUD=false`。
2. 重新执行 `npm.cmd run verify:android`。
3. 使用 HBuilder X 重新打包本地数据版本。
4. 在本文件记录失败云函数、失败输入、控制台错误和当前 Git commit。
5. 不删除本地 port，直到云端连续通过完整真机验证。
