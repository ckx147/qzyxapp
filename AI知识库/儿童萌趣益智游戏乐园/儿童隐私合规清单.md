# 儿童萌趣益智游戏乐园 - 儿童隐私合规清单

标签：#儿童隐私 #合规 #微信小程序

## 用途

这是上线前的产品和技术检查清单，不是法律意见。正式发布前仍需要结合实际运营主体、地区和微信平台规则做法务确认。

## 数据最小化

- [ ] 不采集儿童真实姓名。
- [ ] 不采集手机号、身份证、住址、学校班级等敏感身份信息。
- [ ] 默认使用系统昵称和预设卡通头像。
- [ ] 自定义头像如允许上传，必须提供删除能力，并评估是否需要家长授权。
- [ ] 游戏记录只保存玩法所需字段，不保存聊天、定位、通讯录等无关信息。

## 账号和身份

- [ ] 使用微信登录时，只在服务端保存必要的 openid 标识。
- [ ] 客户端不要暴露 openid 或内部 userId。
- [ ] 如果未来支持多儿童档案，明确家长账号和儿童档案的关系。
- [ ] 不允许用户通过客户端参数访问或修改他人数据。

## 家长授权

- [ ] 首次使用前展示儿童产品相关隐私提示。
- [ ] 明确说明会收集哪些数据：昵称、头像 id、积分、打卡、成就、游戏记录、背包等。
- [ ] 明确说明数据用途：保存进度、积分结算、成就展示、排行榜。
- [ ] 如果开放头像上传、排行榜公开展示或社交功能，单独提示并获得授权。

## 排行榜展示

- [ ] 默认只展示昵称、卡通头像和积分。
- [ ] 不展示真实姓名、地区、学校、联系方式。
- [ ] 优先考虑好友榜、家庭榜或班级小范围榜，谨慎开放全服榜。
- [ ] 提供关闭或隐藏排行榜展示的选项。

## 数据删除和导出

- [ ] 提供清除本地数据入口。
- [ ] 提供注销或删除云端账号数据的入口。
- [ ] 删除范围包括用户档案、积分统计、积分流水、打卡、成就、背包、游戏记录。
- [ ] 删除后排行榜不再展示该用户。
- [ ] 如支持数据导出，导出内容只包含用户自己的数据。

## 云开发权限

- [ ] 云函数统一根据 `_openid` 校验身份。
- [ ] 客户端不能直接写 `point_transactions`。
- [ ] 客户端不能直接改 `user_stats.pointsBalance`。
- [ ] 成就领奖、每日打卡、购买零食、游戏结算都必须做幂等处理。
- [ ] 数据库权限规则默认最小开放。

## 内容和交互

- [ ] 文案避免诱导充值、攀比或过度游戏。
- [ ] 失败反馈保持鼓励，不制造焦虑。
- [ ] 音效和动效不过度刺激。
- [ ] 家长可理解积分、排行榜和成就的含义。

- [ ] 儿童个人信息处理规则或相关说明。
- [ ] 家长授权流程。
- [ ] 数据删除流程。
- [ ] 微信小程序后台隐私接口配置。
