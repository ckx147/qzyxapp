# 版本回溯说明

标签：#版本回溯 #Git #回滚

本工作区使用本地 Git 做版本回溯。仓库根目录：

```text
D:\儿童微信小程序开发
```

## 日常规则

- 每次大改前先建立一个 checkpoint。
- 每次完成一个明确阶段后再提交一个 checkpoint。
- 不满意时优先回到最近的 checkpoint。
- 回退前先看当前未提交改动，避免误删有用内容。

## 常用命令

查看当前改动：

```powershell
git status --short
```

创建版本点：

```powershell
git add .
git commit -m "checkpoint: 简短说明"
```

查看历史版本：

```powershell
git log --oneline --decorate -n 20
```

查看某个文件的改动：

```powershell
git diff -- 路径\文件名
```

回退单个文件到上一个版本：

```powershell
git restore -- 路径\文件名
```

回退到指定版本，需要谨慎：

```powershell
git restore --source <commit_id> -- .
```

```text
先查看 git status 和 git log，给我列出可回退版本，不要直接执行回退。等我确认 commit_id 后，再回退指定文件或整个工作区。
```

## 当前基线

初始 checkpoint 应记录当前 APP 原型和 AI 知识库状态。后续如果对 APP 源码做大改，先提交 checkpoint。
